# Практика 1–4 по Java

Практические работы № 1–4.

- `PR1`–`PR4` — исходный код каждой работы.
- `Otchet_PR1-4.docx` — общий отчёт.

Каждую работу нужно компилировать отдельно: во всех используется пакет `ru.mirea` и класс `Main`.

Пример запуска первой работы (нужен JDK):

```sh
mkdir -p out/PR1
javac -encoding UTF-8 -d out/PR1 PR1/src/ru/mirea/*.java
java -cp out/PR1 ru.mirea.Main
```
